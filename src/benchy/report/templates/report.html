How to read this

  • Resolved means every required hidden check passed, including the repo's own tests (with the original test files restored), staying within the task's allowed paths, and introducing no secrets.
  • pass^k is the share of tasks a contender solved in every repeat. It measures consistency, which matters when a team relies on the tool daily.
  • Cost / resolved divides all spend, failed attempts included, by the number of runs resolved. It is the fairest single cost number.
  • Copilot cost comes from GitHub AI Credits (1 credit = $0.01). Claude Code cost is its own client-side estimate. Costs marked “estimated-from-tokens” use pricing.yaml.
  • Medians are shown with min–max. With few repeats, treat differences smaller than the ranges as noise.
  • “—” means the harness did not report that value, not zero.
